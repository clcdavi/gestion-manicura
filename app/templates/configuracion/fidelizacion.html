Cuando una cliente alcance el número de visitas configurado, el sistema le activará automáticamente un beneficio que podrás aplicar en su próxima atención.

Cada vez que una cliente acumule esta cantidad de visitas, se le activará el beneficio.
Si es descuento: porcentaje (ej: 10 = 10%).
Si es servicio gratis: podés poner 100 (100% de descuento en un servicio).
Ejemplo: Con la configuración actual, después de {{ cfg.visitas_para_beneficio }} visita(s), cada cliente recibe {% if cfg.tipo_beneficio == 'descuento_pct' %} un {{ cfg.valor_beneficio|int }}% de descuento en su próximo servicio. {% else %} un servicio gratis (valor del beneficio: {{ cfg.valor_beneficio|int }}%). {% endif %}
